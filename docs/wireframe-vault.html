Vault — wireframe duyệt trước

Khoá riêng từng nhóm file · nhiều vault · xoá vault thì file hiện lại

Luồng chính

  1. Cài đặt → Vault → danh sách vault.
  2. Tạo vault: tên + mật khẩu + nhập lại.
  3. Mở vault: nhập mật khẩu → màn vault riêng.
  4. Trong vault: tìm kiếm chỉ trong vault đó; thêm file từ thư viện.
  5. Từ thư viện chính: long-press/⋮ → Đưa vào vault → file biến mất khỏi thư viện.
  6. Xoá vault: các file hiện lại, không bị xoá.

Quyết định cần duyệt

  1. Lối vào: Cài đặt → Vault (không thêm tab thứ 6).
  2. 1 file thuộc 1 vault: thêm vào vault khác = chuyển sang vault đó. Muốn 1 file ở nhiều vault?
  3. Bảo vệ: ẩn trong app + mật khẩu. Chưa mã hoá blob — Perkeep Web/Jellyfin vẫn đọc được. Cần mã hoá thật thì làm giai đoạn 2.
  4. Quên mật khẩu: vẫn được xoá vault (gõ tên để xác nhận) để file hiện lại; không mất file. Đồng ý?
  5. Tự khoá: mở khoá giữ trong phiên; nút Khoá; đóng app là khoá. Có cần tự khoá sau 5 phút rời app?
  6. Thêm file: từ trong vault (picker) + từ menu file ngoài. Có cần upload trực tiếp vào vault?
Cơ chế đề xuất (v1)
Mỗi file trong vault được gắn tag pkvault + pkvault-<id>. Mọi tìm kiếm ngoài thư viện tự thêm -tag:pkvault. Xoá vault chỉ gỡ tag, không xoá blob. Mật khẩu lưu dạng PBKDF2-SHA256 + salt, không lưu plaintext. AI/MCP cũng lọc pkvault; vault tự tìm bằng truy vấn riêng.
Giới hạn cần biết: đây là vault cấp app, không phải mã hoá đầu-cuối. Ai mở được Perkeep Web, Jellyfin hoặc dùng client khác vẫn thấy/thao tác được file gốc. Nếu bạn cần “không ai đọc được kể cả khi có server”, phải mã hoá file trước khi upload (giai đoạn 2) — sẽ mất tìm kiếm nội dung/Jellyfin.

Ghi chú kỹ thuật

• Nhiều vault: mỗi vault 1 id + 1 tag riêng, 1 mật khẩu riêng.
• Xoá vault = gỡ tag của toàn bộ file trong vault → hiện lại ở Home/Tệp/tìm kiếm.
• Khôi phục cấu hình (mã backup) sẽ gồm metadata vault + hash mật khẩu; file/tag nằm trong Perkeep.
• Vault không hiện trong bottom nav; màn vault là overlay toàn màn hình.

Bạn duyệt các mục 1–6 ở trên (hoặc ghi chú thay đổi) rồi mình implement.
