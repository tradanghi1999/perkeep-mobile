Ẩn hết: blobref, expression, JSON, log. Chỉ hiện trong Cài đặt → Chẩn đoán.
Nguyên tắc học từ Drive:
  • Thanh tìm kiếm luôn trên cùng, gõ tiếng Việt thường (“ảnh đà lạt”) — app tự dịch sang query Perkeep, không bắt user học tag:.
  • Server = tài khoản Google: đổi bằng avatar, mỗi server có tên + chấm online, thêm mới chỉ 2 ô (tên, địa chỉ).
  • Danh sách file chỉ hiện: icon, tên, ngày, server. Mọi thứ kỹ thuật (blob, describe, POST log) giấu vào “Chi tiết / Chẩn đoán”.
  • 1 nút + duy nhất: Tải ảnh lên / Tạo ghi chú. Bottom nav 4 mục, thao tác file gom vào menu ⋮.
Chốt giúp: (1) Bottom nav 4 mục trên OK chưa? (2) Nút + có cần “Tải ảnh lên” ngay bản đầu không, hay chỉ xem/tìm trước?
